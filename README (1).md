# CCN-RWANDA website

Website for Concern and Care for the Needy in Rwanda (CCN-RWANDA), a registered Rwandan NGO based in Kigali.

It is a single static file, `index.html`, with the styles, scripts and logo built in. There is nothing to install or build.

## View it locally

Open `index.html` in a browser.

## Publish it

The site can be hosted for free with GitHub Pages: in the repository, go to Settings, then Pages, choose the `main` branch and the root folder, and save. The address will be `https://<your-username>.github.io/<repository-name>/`.

## Editing

Page text, colors and contact details are all inside `index.html`. Colors are set once at the top of the file in the `:root` block. The contact form is set up for Netlify Forms and does not send messages on GitHub Pages without a form service.
